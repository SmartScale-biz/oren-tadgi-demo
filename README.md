# הדגמה: המערכת של איקס מדיה שלטים

הדגמה לחיצה, בעברית ו-RTL, של מערכת ניהול ההזמנות, הייצור, ההתקנות והנהלת החשבונות של איקס מדיה שלטים (נתיבות). נבנתה אחרי פגישת ההיכרות עם אורן ב-13.10.2026, לפי מה שאורן הראה בשיתוף המסך: הגיליון של אינה, הטאבים של המכונות, טאב "התקנות לביצוע" לפי אזורים וצוותים, רווחית וקבוצות הווטסאפ. נועדה לפגישת האיפיון של 19.10.2026.

**הכתובת:** https://smartscale-biz.github.io/oren-tadgi-demo/

רספונסיבית לחלוטין: במובייל סרגל טאבים תחתון, בדסקטופ סיידבר (אותו דפוס כמו במערכת של אבי פרימס).

## מה אמיתי ומה דמה

| אמיתי (מהפגישה ומהפריימים) | דמה |
|---|---|
| הזרימה: הזמנה, הצעת מחיר, גרפיקה, אישור לקוח, ייצור, התקנה, תעודת משלוח, חשבונית | כל המחירים והסכומים, מסומנים "לדוגמה" |
| המקרא: אדום דחוף, שמנת נשלח לאישור, סגול בוצע, ירוק טרם הוכן | אנשי הקשר אצל הלקוחות והטלפונים (תבנית 05X-000-NNNN) |
| המכונות: מימאקי, EFI, CNC, DTF, חולצות, זכוכית | הלקוחות שאינם המותגים שאורן הזכיר (שמות בדויים) |
| הצוותים והצבעים מהגיליון: ניסים, ציטה, נועם, מאיר, עידו | מספרי המסמכים והתאריכים (נגזרים מ"היום") |
| האנשים: אורן, סמדר, אינה, ורד, מתן, אבי, אברהם, מירן | הבוט, העוזר והחיבור לרווחית: איורים, בלי מודל חי ובלי API |
| המותגים שאורן הזכיר בעצמו: דלק, מחסני השוק, דימרי, מנטה | |
| הלוגו והאדום של איקס מדיה (מהאתר הציבורי) | |

הנתונים נבנים מחדש לפי התאריך של היום, כדי שההדגמה לא תתיישן. כל לחיצה נשמרת רק בדפדפן (localStorage), ו"איפוס ההדגמה" בפוטר מחזיר הכל להתחלה. דגל אחד ב-`docs/js/data.js` (`USE_BRAND_NAMES = false`) מחליף את שמות המותגים בשמות דמה.

## המסכים

| נתיב | מה זה מוכיח |
|---|---|
| `#/` היום | הלוח של סמדר: מה פתוח, מה ממתין ללקוח, מה בייצור, מי בשטח, "דורש טיפול" ופיד חי |
| `#/orders` הזמנות | רשימה, לוח שלבים עם גרירה, ולפי מכונה. "הזמנה חדשה" מפענחת הודעת ווטסאפ וממלאת את המחיר האחרון ללקוח |
| `#/orders/<מספר>` כרטיס הזמנה | שלבים, גרפיקה ואישור לקוח, ייצור, התקנה, מסמכים, יומן. כל כפתור משנה את המצב |
| `#/graphics` גרפיקה | התור של אינה באותם צבעים של הגיליון, עם שעון "הלקוח לא ענה" |
| `#/production` ייצור | תור לכל מכונה במקום דרייב לכל מכונה, וסקר "מי מבצע" לקבוצת הייצור |
| `#/installs` התקנות | לוח שבועי לפי אזור ובצבעי הצוותים, ולפי צוות |
| `#/installs/route?team=noam&day=1` הסידור | סדר לפי הדרך, ק"מ וזמנים, בדיקת תחנה שנשכחה (יוקנעם), ייצוא ליומן (ics אמיתי) |
| `#/field?team=noam` אפליקציית המתקין | הגעתי, צילום, חתימה אמיתית על המסך, שליחה למשרד ולרווחית |
| `#/accounting` הנהלת חשבונות | סוף חודש: חתומה, הזמנת רכש, חשבונית ומה חסר. הפקה מרוכזת, וקליטת חשבונית ספק בצילום |
| `#/pricing` מחירים | המחיר האחרון ללקוח על פריט ומידה, וההשוואה ללקוחות אחרים |
| `#/studio` סטודיו | שלט סטנדרטי לקובץ PDF בגודל אמיתי, או ישר לייצור |
| `#/assistant` העוזר | שאלות על הנתונים, תשובות מחושבות מנתוני הדמה |
| `#/whatsapp` ווטסאפ (איור) | הקבוצות נשארות ומחוברות: בוט הזמנות, סקר ייצור, סידור לצוות |
| `#/rivhit` רווחית (איור) | רווחית נשארת, המערכת עובדת סביבה, ויומן סנכרון |
| `#/about` על ההדגמה | מה אמיתי, מה דמה, והמודולים |

פרמטרים לבדיקות: `?today=2026-10-19` מקבע את היום, `?shot=1` מכבה אנימציות, `?fresh=1` מנקה מצב, `?tour=1` מריץ את הסיור, `?test=1` רושם הורדות והדפסות במקום לבצע אותן.

## הרצה מקומית

```
cd docs
python -m http.server 8010
```

ואז `http://localhost:8010`. אפשר גם לפתוח את `docs/index.html` ישירות בכרום. צריך אינטרנט רק לפונטים.

## בדיקות

```
node tools/shots.mjs          צילומים + בדיקות קשות, 47 מצבים x 3 רוחבים (1440, 390, 360)
node tools/clickthrough.mjs   לוחץ על כל מה שאפשר בכל מסך, פותח וסוגר כל שיט, ומריץ 12 זרימות מקצה לקצה
node tools/og.mjs             תמונת התצוגה לוואטסאפ (docs/assets/og.png)
```

שני הכלים מקבלים `--url <כתובת>` כדי לבדוק את הגרסה שבאוויר. הגלריה נכתבת ל-`_screens/index.html` (לא בגיט).

הבדיקות שמפילות את `shots.mjs`: שגיאת JS או רשת, גלילה אופקית או חריגה משני צידי המסך, מקף ארוך או בינוני, "לידה", h1 שאינו יחיד, dir/lang, li עם flex, תמונה שבורה, תבנית שדלפה, יעד מגע קטן מ-40px במובייל, טקסט חתוך, תוכן מוסתר מאחורי סרגל הטאבים. ובסטטי: טלפון או מייל שנראים אמיתיים, שמות לקוחות שהוחלט להחליף, ודמוי סוד.

## פריסה

הריפו ציבורי בהכרעת איליה (13.10.2026), כי GitHub Pages בארגון בתוכנית החינמית עובד רק על ריפו ציבורי. האתר מוגש מ-`main`, תיקייה `/docs`. דחיפה ל-`main` מעדכנת את הכתובת תוך דקה או שתיים. `noindex`, לא מופיע בגוגל.
